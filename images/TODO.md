# Illustrations still to draw

90 of the 149 cards are waiting on artwork. Until a file exists, the site renders a
cream "illustration pending" panel carrying the card's caption, so nothing looks broken —
drop the PNG in at the listed path and it appears automatically. No code change needed.

**After adding any images, run `python3 images/resize_images.py`** from the repo root. It
normalises every PNG to the house size of 800×436.

## House style

Every prompt below assumes this preamble:

> Hand-drawn watercolour and ink comic panel, 800×436, on warm cream paper. Soft
> earth-tone palette, visible pencil underdrawing, confident black ink linework, a thin
> ink border framing the panel. Where a caption is called for, hand-letter it in a small
> ruled box in the style of a graphic novel. Friendly and warm, never clinical — readable
> by a curious child and an adult at the same time. No photorealism, no 3D render, no
> stock-illustration flatness.

The caption in each prompt is the card's `prompt` field, which is what the placeholder
currently displays. Keep them identical so the art matches the text.
